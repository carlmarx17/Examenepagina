# Simulacro ICFES Salomé

Página web estática para practicar un simulacro ICFES de nivel intermedio-difícil:

- 80 preguntas.
- Duración de 2 horas.
- Matemáticas y ciencias naturales.
- Énfasis en geometría: 45 preguntas.
- Revisión automática con explicación por pregunta.
- Guardado local de respuestas mientras se resuelve.

## Uso local

Abre `index.html` directamente en el navegador.

## Publicar en GitHub Pages

1. Sube estos archivos a un repositorio de GitHub.
2. En GitHub, entra a `Settings` > `Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/root`.
5. Guarda los cambios y espera a que GitHub genere la URL.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño responsive.
- `app.js`: preguntas, temporizador, filtros, calificación y revisión.
